# Community Skiller Program Path

Community Skiller wants to build leadership skills by hosting Microsoft Learn Plans that include Microsoft Learn training content. Registered members who choose the Community Skiller program path must complete the check-marked activities below to be invited to onboard into the program. Invitations are sent quarterly in January, April, July, and October.

* Create and host Microsoft Learn Plans using your Contributor ID so that plan participants complete 1,000 net-new modules
* Earn a Microsoft Certification or Microsoft Applied Skills credential within 12 months before onboarding

## What is Contributor ID and how do I get it?

Students who register for the Student Ambassadors program receive a Contributor ID to use when completing required program path activities. This ID is used to track progress toward becoming a Student Ambassador. The ID does not change for as long as you remain a registered member. Students receive their Contributor ID by email within 3–5 days after registering for the program.

The general format is shown below, with `#` replaced by unique numbers:
* **Contributor ID format:** `?wt.mc_id=studentamb_######`

> **Important note:** Anyone with a Learn profile also has a Learn Contributor ID. You can find it in the Learn profile under Settings / Contributor ID. Make sure you use your Student Ambassadors Contributor ID, not your Learn Contributor ID.

## How do I create a Microsoft Learn Plan?

Create a Learn Plan according to the Microsoft Learn guidance. When creating the plan, use the [Create plan] button and include your Contributor ID at the end of the plan description. First save Learn content to a collection. Then, from the collection page, copy it to convert the collection into a plan. After that, publish the plan and share it with your local and online communities. Be sure to include your Contributor ID at the end of the plan description.

> **Important note:** During registration, you were asked to provide your Learn username. If you did not provide a Learn username, or if you included unnecessary information in the Learn username field, you must delete the registration and register again.

### Steps to create a Microsoft Learn Plan
1. On Microsoft Learn, save content to a collection and set it to Public.
2. From the collection page, copy it to a plan.
3. Add your Contributor ID to the end of the plan description.
4. Publish the plan and share it with your community.

> The Learn platform may automatically append a Learn Contributor ID. Keep it and also add your Student Ambassadors Contributor ID. If your ID starts with `?wt.mc_id`, change the `?` to `&` before adding it to the URL.

## How do I add my Contributor ID to a plan link?

Students who choose the Community Skiller path append their Contributor ID to the end of the plan link and share the modified URL with local and online communities.

**Example:**
* After creating the plan, click Share and then click Copy link.
* The link has the format `https://learn.microsoft.com/plans/XXXXXXXXXXXXXX?sharingId=XXXXXXXXXXXXXXXX`.
* Modify the link by adding your Contributor ID to the end of the URL.
* New link: `https://learn.microsoft.com/plans/XXXXXXXXXXXXXX?sharingId=XXXXXXXXXXXXXXXX&wt.mc_id=studentamb_######`

> **Important note:** The Learn platform automatically appends a Learn Contributor ID to the end of the plan link. Add your Student Ambassadors Contributor ID as well. If your ID starts with `?`, change it to `&` before appending it to the URL.

---

## Common fixes

* **Missing sharingId in the link:** Re-copy the link from Share and then add your ID.
* **Private collection:** Set the collection to Public before converting it to a plan.
* **Wrong ID used:** Replace the Learn profile Contributor ID with the Student Ambassadors Contributor ID.

## What are net-new completed modules?

Completed modules are modules that a plan participant completed before joining the plan. Net-new completed modules are modules that the plan participant completed after joining the plan.

**Example:**
* Henri completed the “Cloud Computing Overview” module in August 2025.
* Henri’s friend Maria is preparing to become an Ambassador.
* Maria creates a Learn Plan that includes the “Cloud Computing Overview” module.
* Henri joins Maria’s Learn Plan using the invitation link in September 2025.
* Henri has 1 completed module, but 0 net-new completed modules.

## How do I check my net-new module count?

Reporting emails are sent weekly and may take up to 48 hours to finish processing. Activities completed within 48 hours of the email send time may not be included in that week’s count. You can also check the count on the Progression Board, which is a me-only screen. In other words, it shows only the progress of the registered student. The Progression Board is updated at the same time the reporting email is sent.

* If you have not received your first reporting email, the me-only screen will be empty.
* If you have received your first reporting email, the me-only screen will show your count.

| Program path | Reporting email sent | Progression Board updated |
|---|---|---|
| Community Influencer | Every Saturday, Pacific Time | Every Saturday, Pacific Time |
| Community Skiller | Every Saturday, Pacific Time | Every Saturday, Pacific Time |

## Why is the count different from what I expected?

If the reported net-new count is different from what you expected, the plan participants may not have joined or used the plan correctly.

| Activity | Example |
|---|---|
| **Plan participation** | The participant did not click [Start] on the plan page and did not agree to share progress, removed their learning progress from the plan by clicking [Leave] on the plan tile, or completed the plan module before joining the plan. |
| **Plan activity** | The participant engaged in activity that violates Microsoft’s terms of service, including the policy prohibiting manipulation of play counts. |

> **Important:** Spam, scripting, or any activity or behavior that violates the Microsoft Services Agreement, the registered member rules, or any other terms agreed to during registration and/or SharePoint site sign-in is prohibited. Microsoft reserves the right to request Community Influencer count verification from all registered members.
