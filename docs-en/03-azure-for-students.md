# Azure for Students

**Mandatory Requirement**

This is the setup guide for registered Microsoft Student Ambassadors. Please follow every step carefully — this requirement cannot be bypassed.

> ⚠️ **Required:** Azure for Students is currently a **mandatory program requirement** that cannot be bypassed or substituted. You must complete all tasks before you can be considered for quarterly onboarding.

### STEP 1 — Verify Academic Eligibility

Microsoft requires academic verification before activating your Azure for Students account: [**Verify Academic Eligibility**](https://learn.microsoft.com/en-us/microsoft-365/commerce/subscriptions/verify-academic-eligibility?view=o365-worldwide#verify-your-schools-academic-eligibility)

> ⚠️ Make sure **pop-ups are enabled** in your browser. The verification link will not load correctly if pop-ups are blocked.

### STEP 2 — No Valid School Email?

If you do not have a valid school email, you can instead submit a **valid school document**. As a fallback, the [**GitHub Student Developer Pack**](https://education.github.com/pack) can help you complete the verification process.

### STEP 3 — Regional Restrictions

Azure services are **not available in all countries or regions.** Availability depends on Microsoft’s global infrastructure, compliance, and regulatory requirements. Check availability in your region here: [**Azure Products by Region**](https://azure.microsoft.com/en-us/explore/global-infrastructure/products-by-region/) ↗ | [Azure Regions List](https://learn.microsoft.com/en-us/azure/reliability/regions-list) ↗

> 🚫 The Student Ambassadors program **cannot override** regional Azure restrictions.

### 🛠️ Need Azure support directly?

The Student Ambassadors team **cannot directly handle** Azure for Students support issues. For Azure technical issues, use Microsoft’s official support channels: [**Azure Support Options**](https://azure.microsoft.com/en-us/support/options/). You can also submit a support ticket directly through the Azure Support portal.

### 📩 Program-related questions only

For questions specifically about registration, contact: [**registration@studentambassadors.com**](mailto:registration@studentambassadors.com)

> 💡 **Tip:** The Discord operations team works in Pacific Time (PST) and responds within **1–2 business days**. Please avoid sending duplicate emails for the same issue.
