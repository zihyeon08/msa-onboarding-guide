# Azure for Students

**• 필수 요구 사항**

등록된 Microsoft Student Ambassadors를 위한 설정 가이드입니다. 모든 단계를 주의 깊게 따라주세요 — 이 요구 사항은 우회할 수 없습니다.

> ⚠️ **필수:** Azure for Students는 현재 우회하거나 대체할 수 없는 **필수 프로그램 요건**입니다. 분기별 온보딩 심사 대상이 되려면 모든 과제를 완료해야 합니다.

### STEP 1 — 학업 자격 확인

Microsoft는 Azure for Students 계정을 활성화하기 전에 학업 인증이 필요합니다: [**학업 자격 확인하기**](https://learn.microsoft.com/en-us/microsoft-365/commerce/subscriptions/verify-academic-eligibility?view=o365-worldwide#verify-your-schools-academic-eligibility)

> ⚠️ 브라우저에서 **팝업이 허용**되어 있는지 확인하세요. 팝업이 차단되면 인증 링크가 제대로 로드되지 않습니다.

### STEP 2 — 유효한 학교 이메일이 없는 경우

유효한 학교 이메일이 없다면, **유효한 학교 서류**를 대신 제출할 수 있습니다. 대안으로 [**GitHub Student Developer Pack**](https://education.github.com/pack)을 이용하면 인증 과정을 완료하는 데 도움이 됩니다.

### STEP 3 — 지역 제한

Azure 서비스는 **모든 국가 또는 지역에서 제공되지 않습니다.** 가용성은 Microsoft의 글로벌 인프라, 규정 준수 및 규제 요건에 따라 달라집니다. 해당 지역의 가용성을 확인하세요: [**지역별 Azure 제품 목록**](https://azure.microsoft.com/en-us/explore/global-infrastructure/products-by-region/) ↗ | [Azure 지역 목록](https://learn.microsoft.com/en-us/azure/reliability/regions-list) ↗

> 🚫 Student Ambassadors 프로그램은 **지역별 Azure 제한을 재정의할 수 없습니다.**

### 🛠️ Azure 지원이 필요하신가요?

Student Ambassadors 팀은 Azure for Students 지원 문제를 **직접 처리할 수 없습니다**. Azure 기술 문제의 경우 Microsoft 공식 지원 채널을 이용하세요: [**Azure 지원 옵션**](https://azure.microsoft.com/en-us/support/options/). Azure Support 포털을 통해 직접 지원 티켓을 제출할 수도 있습니다.

등록에 관한 문의는 이쪽으로 연락하세요: [**registration@studentambassadors.com**](mailto:registration@studentambassadors.com)
