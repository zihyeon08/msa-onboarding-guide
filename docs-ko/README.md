## 한국어 버전

Microsoft Student Ambassadors(MSA) 프로그램에 처음 합류하는 사람을 위한 자료집입니다. 이미 공식 이메일을 부여받아 MSA가 되었다면, Program Handbook 내용을 확인하세요.

### 빠른 시작

1. **프로그램 이해** — MSA가 무엇인지, 왜 참여하는지 확인 → [01-overview.md](01-overview.md)
2. **등록 및 흐름 파악** — 공식 등록 사이트에서 신청 후 Step 1~5 등록 프로세스와 전체 플로우차트 확인 → [02-registration.md](02-registration.md)
3. **Azure for Students 설정** — 필수 요건이므로 등록 직후 완료 → [03-azure-for-students.md](03-azure-for-students.md)
4. **경로 선택** — Community Influencer 또는 Community Skiller 중 하나 선택 → [04-path-selection.md](04-path-selection.md)
5. **경로별 활동 시작** — 선택한 경로의 상세 가이드 따라 진행 → [05-community-influencer.md](05-community-influencer.md) / [06-community-skiller.md](06-community-skiller.md)
6. **Contributor URL 만들기** — 콘텐츠 URL에 Contributor ID를 붙이는 실전 안내 → [08-contributor-url.md](08-contributor-url.md)
