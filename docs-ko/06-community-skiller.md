# Community Skiller Program Path

Community Skiller는 Microsoft Learn Plans를 개최하여 Microsoft Learn 교육 콘텐츠를 제공함으로써 리더십 역량을 키우고 싶어합니다. Community Skiller 프로그램 경로를 선택한 등록 회원은 프로그램 온보딩 초대를 받기 위해 아래 체크 표시된 활동을 완료해야 합니다. 초대는 1월, 4월, 7월, 10월 분기별로 발송됩니다.

* Contributor ID를 사용해 Microsoft Learn Plans를 제작하고 개최하여 플랜 참가자가 완료한 net-new 모듈 1,000개 달성
* 온보딩 12개월 이내에 Microsoft Certification 또는 Microsoft Applied Skills 자격증 취득

---

## 체크리스트
* **필수 활동**
  * Contributor ID를 사용해 Microsoft Learn Plans를 제작하고 개최하여 플랜 참가자가 net-new 모듈 1,000개를 완료하도록 하세요. ✓
  * 온보딩 12개월 이전에 Microsoft Certification 또는 Microsoft Applied Skills 자격증을 취득하세요. ✓

> **중요:** 등록 시 Learn 사용자명이 누락되었거나 불필요한 텍스트가 포함된 경우, 등록을 삭제하고 다시 등록하세요. 그렇지 않으면 자격증이 올바르게 인덱싱되지 않습니다.

---

## Contributor ID란 무엇이며 어떻게 받나요?
Student Ambassadors 프로그램에 등록한 학생들은 필수 프로그램 경로 활동을 완료할 때 사용할 Contributor ID를 받습니다. 이 ID는 Student Ambassador가 되기까지의 진행 상황을 추적하는 데 사용됩니다. ID는 등록 회원 기간 동안 변경되지 않습니다. 학생들은 프로그램 등록 후 3~5일 이내에 이메일로 Contributor ID를 받게 됩니다.

ID의 일반적인 형식은 아래와 같으며, `#` 기호는 고유한 숫자로 대체됩니다:
* **Contributor ID 형식:** `?wt.mc_id=studentamb_######`

> **중요 공지:** Learn 프로필이 있는 모든 사용자에게는 Learn Contributor ID도 있습니다. 이 ID는 Learn 프로필의 설정 / Contributor ID에서 확인할 수 있습니다. Student Ambassadors Contributor ID를 사용하고, Learn Contributor ID를 사용하지 않도록 주의하세요.

---

## Microsoft Learn Plan을 어떻게 만드나요?
Microsoft Learn의 가이던스에 따라 Learn Plan을 만드세요. 플랜 생성 시 [플랜 만들기] 버튼을 사용하고 플랜 설명 끝에 Contributor ID를 포함하세요. 먼저 Learn 콘텐츠를 컬렉션에 저장합니다. 다음으로 컬렉션 페이지에서 복사하여 컬렉션을 플랜으로 변환합니다. 이후 플랜을 게시하고 로컬 및 온라인 커뮤니티와 공유합니다. 플랜 설명 끝에 Contributor ID를 반드시 포함하세요.

> **중요 공지:** 프로그램 등록 시 Learn 사용자명을 제공하도록 요청받았습니다. Learn 사용자명을 제공하지 않았거나, Learn 사용자명 필드에 불필요한 정보를 포함했다면 등록을 삭제하고 다시 등록해야 합니다.

### Microsoft Learn Plan 만들기 단계
1. Microsoft Learn에서 콘텐츠를 컬렉션에 저장하고 공개로 설정합니다.
2. 컬렉션 페이지에서 플랜으로 복사합니다.
3. 플랜 설명 끝에 Contributor ID를 추가합니다.
4. 플랜을 게시하고 커뮤니티와 공유합니다.

> Learn 플랫폼이 자동으로 Learn Contributor ID를 추가할 수 있습니다. 이를 그대로 두고 Student Ambassadors Contributor ID도 추가하세요. ID가 `?wt.mc_id`로 시작하는 경우, URL에 추가하기 전에 `?`를 `&`로 변경하세요.

## 플랜 링크에 Contributor ID를 추가하는 방법은?
Community Skiller 경로를 선택한 학생들은 플랜 링크 끝에 Contributor ID를 추가하고 수정된 URL을 로컬 및 온라인 커뮤니티와 공유합니다.

**예시:**
* 플랜을 만든 후 공유를 클릭하고 링크 복사를 클릭합니다.
* 링크는 `https://learn.microsoft.com/plans/XXXXXXXXXXXXXX?sharingId=XXXXXXXXXXXXXXXX` 형식입니다.
* URL 끝에 Contributor ID를 추가하여 링크를 수정합니다.
* 새 링크: `https://learn.microsoft.com/plans/XXXXXXXXXXXXXX?sharingId=XXXXXXXXXXXXXXXX&wt.mc_id=studentamb_######`

> **중요 공지:** Learn 플랫폼은 플랜 링크 끝에 자동으로 Learn Contributor ID를 추가합니다. Student Ambassadors Contributor ID도 추가하세요. ID의 `?`를 `&`로 교체한 후 URL 끝에 추가하면 됩니다.

---

## 자주 묻는 문제 해결
* **링크에 sharingId 누락:** 공유에서 링크를 다시 복사한 후 ID를 추가하세요.
* **비공개 컬렉션:** 플랜으로 변환하기 전에 컬렉션을 공개로 설정하세요.
* **잘못된 ID 사용:** Learn 프로필 Contributor ID를 Student Ambassadors Contributor ID로 교체하세요.

---

## net-new 완료 모듈이란 무엇인가요?
완료된 모듈이란 플랜 참가자가 플랜에 참가하기 전에 완료한 모듈입니다. Net-new 완료 모듈이란 플랜 참가자가 플랜에 참가한 후에 완료한 모듈입니다.

**예시:**
* Henri는 2025년 8월에 '클라우드 컴퓨팅 개요' 모듈을 완료했습니다.
* Henri의 친구 Maria는 Ambassador가 되기 위해 준비 중입니다.
* Maria는 '클라우드 컴퓨팅 개요' 모듈이 포함된 Learn Plan을 만듭니다.
* Henri는 2025년 9월에 Maria의 초대 링크를 사용하여 Learn Plan에 참가합니다.
* Henri는 모듈 완료 수는 1개이지만, net-new 완료 모듈 수는 0개입니다.

## net-new 완료 모듈 카운트는 어떻게 확인하나요?
리포팅 이메일은 매주 발송되며 처리 완료까지 최대 48시간이 소요될 수 있습니다. 이메일 발송 48시간 이내의 활동은 해당 주 집계에 포함되지 않을 수 있습니다. Progression Board에서도 카운트를 확인할 수 있으며, 이는 나만 볼 수 있는(Me-only) 화면입니다. 즉, 등록 학생 본인의 진행 상황만 확인 가능합니다. Progression Board는 리포팅 이메일 발송 시점에 함께 업데이트됩니다.

* 첫 번째 리포팅 이메일을 받지 못한 경우, 나만 볼 수 있는 화면이 비어 있습니다.
* 첫 번째 리포팅 이메일을 받은 경우, 나만 볼 수 있는 화면에 카운트가 표시됩니다.

| 프로그램 경로 | 리포팅 이메일 발송 | Progression Board 업데이트 |
|---|---|---|
| Community Influencer | 매주 토요일, 태평양 표준시 | 매주 토요일, 태평양 표준시 |
| Community Skiller | 매주 토요일, 태평양 표준시 | 매주 토요일, 태평양 표준시 |

---

## 예상과 카운트가 다른 이유는?
보고된 net-new 카운트가 예상과 다른 경우, 플랜 참가자들이 플랜에 제대로 참가하거나 활동하지 않았을 가능성이 높습니다.

| 활동 | 예시 |
|---|---|
| **플랜 참가** | 플랜 페이지에서 [시작하기]를 클릭하지 않고 진행 상황 공유에 동의하지 않은 경우, 플랜 타일에서 [탈퇴]를 클릭하여 플랜에서 학습 진행 상황이 제거된 경우, 또는 플랜 시작 전에 플랜 모듈을 완료한 경우 |
| **플랜 활동** | 플레이 카운트 조작 금지 조항을 포함한 Microsoft 서비스 약관을 위반하는 활동에 참여한 경우 |

> **중요 공지:** 프로그램 등록 및/또는 SharePoint 사이트 서명 시 동의한 Microsoft 서비스 약관, 등록 회원 규정 및 기타 이용약관을 위반하는 스팸, 스크립팅 또는 기타 활동이나 행위는 금지됩니다. Microsoft는 모든 등록 회원에게 Community Influencer 카운트 검증을 요청할 권리를 보유합니다.
