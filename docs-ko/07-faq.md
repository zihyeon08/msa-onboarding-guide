# 자주 묻는 질문 (FAQ)

**Q1. Community Influencer 경로에서 카운트가 반영되지 않는 이유는 무엇인가요?**
* **A.** URL 끝에 Contributor ID(`?wt.mc_id_xxxxx`)가 첨부되어 있는지 확인하세요. 등록 회원 핸드북 및 Discord 게시물에 제공된 가이던스를 따르고 있는지 확인하세요.

**Q2. Community Skiller 경로에서 카운트가 반영되지 않는 이유는 무엇인가요?**
* **A.** URL 끝에 Contributor ID(`?wt.mc_id_xxxxx`)가 첨부되어 있는지 확인하세요. 플랜 설명 내에도 Contributor ID가 포함되어 있는지 확인하세요. 등록 회원 핸드북 및 Discord 게시물에 제공된 가이던스를 따르고 있는지 확인하세요.

**Q3. 저는 처음 시작합니다. 무엇을 해야 하나요?**
* **A.** Microsoft Student Ambassadors(MSA)와 함께하는 여정을 시작하신 것을 축하드립니다! MSA가 되려면 학생들은 프로그램 규정에 따라 관심사와 역량에 맞는 사전 정의된 활동을 완료해야 합니다. 이메일로 전송된 등록 회원 핸드북이 포함된 리소스를 확인하세요.

**Q4. 모든 과제를 완료했습니다. 언제 온보딩되나요?**
* **A.** MSA가 되기 위한 첫 번째 단계를 완료하신 것을 축하드립니다! SA 프로그램은 온보딩 요건을 충족한 학생들을 분기별로 심사합니다. 각 분기 심사 마감일은 해당 분기의 마지막 날이며, 온보딩은 다음 분기 시작 시 이루어집니다. 프로그램 분기는 다음과 같습니다:
  * **1~3월** (3월 31일 오후 11:59 PST까지 진행; 4월에 온보딩)
  * **4~6월** (6월 30일 오후 11:59 PST까지 진행; 7월에 온보딩)
  * **7~9월** (9월 30일 오후 11:59 PST까지 진행; 10월에 온보딩)
  * **10~12월** (12월 31일 오후 11:59 PST까지 진행; 1월에 온보딩)

**Q5. 분기 내에 요건을 완료하지 못했습니다.**
* **A.** 걱정하지 마세요! 진행 상황은 다음 분기로 이월됩니다. 계정 비활성화를 방지하기 위해 프로그램 요건에 따라 진행 상황(활발히 공유 중)이 있는지 확인하세요.

**Q6. Microsoft 자격증에는 어떤 옵션이 있나요?**
* **A.** Microsoft SA 프로그램은 두 가지 자격증을 요건 중 하나로 인정합니다.
  * **Microsoft Certification Exam:** 감독관 감독 하에 진행되는 유료 시험입니다. Microsoft Learn에는 GitHub 자격증도 있으며 이 또한 인정됩니다. Microsoft는 정기적으로 자격증 시험 할인 쿠폰 프로모션을 진행하므로 Learn 웹사이트, LinkedIn, 소셜 미디어를 주시하세요!
  * **Microsoft Applied Skills:** 감독관 없이 실습 기반으로 진행되는 무료 평가입니다.

**Q7. MVP 프로필에 '검토 중'이라고 표시됩니다. 무엇을 의미하나요?**
* **A.** 모든 등록자는 프로그램 신청 시 Ambassador가 되기 위한 모든 과제를 완료하고 프로그램에 온보딩될 때까지 '검토 중' 상태가 됩니다. 이 상태가 표시되더라도 걱정할 필요 없습니다. 등록 회원 핸드북에 따라 과제를 완료하면 됩니다.

**Q8. MVP 포털에서 등록에 접근할 수 없습니다.**
* **A.** 모든 등록자는 Azure for Students 계정을 보유하고 MVP 포털에 연결해야 합니다.
  * **단계:**
    1. MVP 포털(`https://mvp.microsoft.com/studentambassadors.com`)에 로그인합니다.
    2. 우측 상단의 프로필 타일 → 내 계정을 클릭합니다.
    3. Azure For Students 프로세스를 완료합니다. (Azure for Students 신청)
    4. 3단계 완료 후 등록에 접근할 수 있게 됩니다.
