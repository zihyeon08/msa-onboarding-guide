# Community Influencer Program Path

Community Influencer는 Microsoft 콘텐츠를 제작하고 공유하여 청중을 유치하고, 인게이지먼트를 높이며, 관계를 구축함으로써 온라인 영향력을 키우고 싶어합니다. Community Influencer 프로그램 경로를 선택한 등록 회원은 프로그램 온보딩 초대를 받기 위해 필수 활동을 완료해야 합니다. 초대는 1월, 4월, 7월, 10월 분기별로 발송됩니다.

- Contributor ID를 사용해 콘텐츠를 제작하고 공유하여 적격 Microsoft URL에 250 Preferred Visitors 달성
- 온보딩 12개월 이내에 Microsoft Certification 또는 Microsoft Applied Skills 자격증 취득

---

## Contributor ID란 무엇이며 어떻게 받나요?

Student Ambassadors 프로그램에 등록한 학생들은 필수 프로그램 경로 활동을 완료할 때 사용할 Contributor ID를 받습니다. 이 ID는 Student Ambassador가 되기까지의 진행 상황을 추적하는 데 사용되며, 등록 회원 기간 동안 변경되지 않습니다. 학생들은 프로그램 등록 후 3~5일 이내에 이메일로 Contributor ID를 받게 됩니다.

ID의 일반적인 형식은 아래와 같으며, `#` 기호는 고유한 숫자로 대체됩니다:

- **Contributor ID 형식:** `?wt.mc_id=studentamb_######`

> **중요 공지:** Learn 프로필이 있는 모든 사용자에게는 Learn Contributor ID도 있습니다. 이 ID는 Learn 프로필의 설정 / Contributor ID에서 확인할 수 있습니다. Student Ambassadors Contributor ID를 사용하고, Learn Contributor ID를 사용하지 않도록 주의하세요.

---

## 콘텐츠 URL에 Contributor ID를 추가하는 방법은?

Community Influencer 경로를 선택한 예비 Ambassador 학생들은 적격 Microsoft URL 끝에 Contributor ID를 추가하여 온라인 커뮤니티에 콘텐츠를 공유합니다.

URL을 처음부터 만드는 순서와 공유 전 확인 항목은 [Contributor URL 만들기](08-contributor-url.md)에서 단계별로 확인할 수 있습니다.

**예시:**

1. 공유하려는 링크: `https://learn.microsoft.com/en-us/copilot?WT.mc_id=academic`
2. 언어-지역 코드를 제거하여 링크 수정: `https://learn.microsoft.com/copilot?WT.mc_id=academic`
3. `?`를 `&`로 교체하여 URL 끝에 Contributor ID를 추가해 링크 수정
4. 새 링크: `https://learn.microsoft.com/copilot?WT.mc_id=academic&wt.mc_id=studentamb_######`

## 어떤 Microsoft URL이 Contributor ID와 함께 사용 가능한가요?

아래에 나열된 Microsoft URL의 경로만 Contributor ID와 함께 사용할 수 있습니다. 해당 ID가 포함된 링크를 클릭하여 이 URL들의 경로를 방문한 Preferred Visitors가 카운트 데이터에 반영됩니다.

| 적격 Microsoft URL                 |                                    |
| ---------------------------------- | ---------------------------------- |
| azure.microsoft.com                | imaginecup.microsoft.com           |
| blog.fabric.microsoft.com          | learn.microsoft.com                |
| code.visualstudio.com              | learn.microsoft.com/copilot        |
| community.fabric.microsoft.com     | microsoft.com/microsoft-cloud/blog |
| devblogs.microsoft.com             | microsoft.com/microsoft-fabric     |
| developer.microsoft.com            | microsoft.com/startups             |
| dotnet.microsoft.com               | mvp.microsoft.com                  |
| events.microsoft.com               | reactor.microsoft.com              |
| foundershub.startups.microsoft.com | techcommunity.microsoft.com        |

> **중요 공지:** Microsoft Learn Plans는 Contributor ID와 함께 사용할 수 없으며, Learn Plans로의 트래픽은 Community Influencer Preferred Visitor 카운트에 포함되지 않습니다.

## Preferred Visitors란 무엇인가요?

Preferred Visitors는 독점 지표로, 구체적인 기준은 공개되지 않습니다. 콘텐츠를 공유할 때 Community Influencer는 경로의 더 큰 목적(청중 유치, 인게이지먼트 촉진, 관계 구축)에 집중하여 가치 있는 경험을 만들어야 합니다.

| 경험               | 예시                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **가치 있는 경험** | LinkedIn에서 정기적으로 자격증 콘텐츠를 공유하는 등록 회원이 최근 게시된 FreeCodeCamp 자격증 강좌를 소개하는 TechCommunity 블로그 링크를 Contributor ID와 함께 공유합니다. 1촌 인맥들이 링크를 클릭하고 블로그를 읽습니다. 여러 1촌 인맥들이 콘텐츠를 재공유합니다. 2촌 인맥들이 링크를 클릭하고 블로그를 읽으며, 처음 콘텐츠를 공유한 등록 회원을 팔로우하기 시작합니다. |
| **가치 없는 경험** | WhatsApp 메시징 플랫폼에서 등록 회원이 채팅방에 링크를 스팸으로 보내고 클릭을 요청합니다. 메시지는 특정 관심사나 역량과 관련이 없으며, 금방 대화 목록 위로 밀려납니다.                                                                                                                                                                                                    |

## 실행 팁

**과제:** Microsoft 기술 관련 콘텐츠, 업데이트, 게시물, 블로그를 공유해야 합니다.

카운트가 증가하지 않는다면 아래 지침을 먼저 확인하세요. 공유 링크의 개수보다 공개성, 콘텐츠의 관련성, 정기적인 큐레이션과 커뮤니티 참여가 중요합니다.

1. **공개 소셜 네트워크**(Facebook, Instagram, Reddit, X, YouTube, LinkedIn, 블로그 등)에만 공유하세요. 메시지 앱이나 이메일은 해당되지 않습니다. SA 팀이 공개적으로 볼 수 있어야 하므로 필수입니다!
2. 핸드북에 제공된 웹사이트의 다양한 링크를 정기적으로 순환하세요(홈페이지가 아닌 서브사이트). 커뮤니티에 흥미로운 기술을 찾기 위해 소셜 미디어나 웹사이트 자체를 탐색하세요.
3. 홈페이지 링크는 피하세요! 또한 정기적으로 게시하는 습관을 들이세요. 가급적 매주 또는 격주로 공유하는 링크에 대해 큐레이팅된 게시물을 작성하세요.
4. 한 게시물에 2~3개 이하의 링크만 공유하세요. 그렇지 않으면 스팸으로 표시될 수 있습니다!
5. 공유한 링크에 대해 **큐레이팅된 콘텐츠를 작성**하세요. 카운트를 요청하지 마세요!
6. **Bitly(비틀리)와 같은 제3자 URL 단축기를 사용하지 마세요.** 원래 URL의 Contributor ID 추적과 카운트 시스템에 영향을 줄 수 있습니다.
7. 활발하고 규모가 큰 커뮤니티/팔로워를 유지하여 매주 더 많은 Preferred Visitors를 확보하세요. 비공개 계정이나 소규모 네트워크는 카운트 진행을 정체시키거나 느리게 할 수 있습니다.
8. 게시물에 다른 사용자를 태그하고 그들의 네트워크에서 재공유를 요청하세요. 도달 범위를 높이는 데 효과적이며, 특히 LinkedIn에서 효과적입니다.
9. Microsoft Learn Plans는 Community Influencer 경로에 적합하지 않습니다.

## Preferred Visitors 카운트는 어떻게 확인하나요?

리포팅 이메일은 매주 발송되며 처리 완료까지 최대 48시간이 소요될 수 있습니다. 이메일 발송 48시간 이내의 활동은 해당 주 집계에 포함되지 않을 수 있습니다. Progression Board에서도 카운트를 확인할 수 있으며, 이는 나만 볼 수 있는(Me-only) 화면으로 등록 학생 본인의 진행 상황만 확인 가능합니다. Progression Board는 리포팅 이메일 발송 시점에 함께 업데이트됩니다.

- 첫 번째 리포팅 이메일을 받지 못한 경우, 나만 볼 수 있는 화면이 비어 있습니다.
- 첫 번째 리포팅 이메일을 받은 경우, 나만 볼 수 있는 화면에 카운트가 표시됩니다.

| 프로그램 경로        | 리포팅 이메일 발송         | Progression Board 업데이트 |
| -------------------- | -------------------------- | -------------------------- |
| Community Influencer | 매주 토요일, 태평양 표준시 | 매주 토요일, 태평양 표준시 |
| Community Skiller    | 매주 토요일, 태평양 표준시 | 매주 토요일, 태평양 표준시 |

## 예상과 카운트가 다른 이유는?

보고된 Preferred Visitor 카운트가 예상과 다른 경우, 콘텐츠가 가치 있는 경험으로 공유되지 않았을 가능성이 높습니다.

> **Preferred Visitors 안내 (2025-11-03):** Preferred Visitors는 독점 지표이므로 세부 산정 기준은 공개되지 않습니다. 청중을 유치하고, 인게이지먼트를 높이며, 관계를 구축하는 가치 있는 경험을 만드는 데 집중하세요.

> **중요 공지:** 프로그램 등록 및/또는 SharePoint 사이트 서명 시 동의한 Microsoft 서비스 약관, 등록 회원 규정 및 기타 이용약관을 위반하는 스팸, 스크립팅 또는 기타 활동이나 행위는 금지됩니다. Microsoft는 모든 등록 회원에게 Community Influencer 카운트 검증을 요청할 권리를 보유합니다.
