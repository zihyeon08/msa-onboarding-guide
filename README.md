### GitHub Issue Guide - en

- When the document content differs from the original source
- When a link is broken or a file cannot be found
- When tables, ordering, or terminology are incorrect
- When additional source material should be included

Please include the following details so we can review it quickly:

1. The file or document name
2. What is incorrect
3. The correct content shown in the source
4. A screenshot or source location if possible

### GitHub Issue 작성 가이드 - ko

- 문서 내용이 원문과 다를 때
- 링크가 깨지거나 파일을 찾을 수 없을 때
- 표, 순서, 용어가 잘못 정리되었을 때
- 추가로 반영해야 할 원본 자료가 있을 때

작성할 때는 아래 정보를 함께 적어주세요.

1. 문제 파일명 또는 문서명
2. 어떤 부분이 잘못되었는지
3. 원본에서 확인되는 올바른 내용
4. 가능하면 스크린샷 또는 원본 위치
